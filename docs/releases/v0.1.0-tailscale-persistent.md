# v0.1.0 - 2026-10-01 — `tailscale-persistent`

Initial release of the `tailscale-persistent` skill.

## Added

- Install flow for Tailscale on Ubuntu/Debian (apt keyring + source, or warm local `.deb` cache).
- First-time tailnet bind (`tailscale up --hostname=<node-name> --ssh`) with login-URL auth.
- Persist layout (`restore.sh`, `units/`, `debs/`, `backups/`) so a root-filesystem reset needs no re-auth.
- Idempotent `assets/restore.sh`: local `.deb`s first, apt fallback, identity + keyring restore, official-unit configuration, `tailscale up`, verification, backup refresh.
- `assets/tailscaled-override.conf` drop-in for proxy env cleanup on the official unit.
- Watchdog contract: root checks, quiet-unless-broken, at most one restore per cycle.
- Runbooks: `references/restore-pattern.md`, `references/troubleshooting.md`.

## Validation

- Two real platform resets on 2026-10-01: 19s and 15s recoveries from a warm local `.deb` cache, node identity preserved, no re-auth.
- `python3 -m unittest discover tests -v` for repo docs.
